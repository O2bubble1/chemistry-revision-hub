# Agent Guide

## Project map

- `src/content/`: source JSON. Treat it as curriculum data, not UI code.
- `src/features/lessons/`: schema, validation, and typed block renderer.
- `src/features/quizzes/`, `src/features/flashcards/`, `src/features/periodic-table/`: study tools.
- `src/components/ui/`: shadcn-generated components. Do not hand-roll replacements.
- `.github/workflows/pages.yml`: quality checks and dependent GitHub Pages deploy.
- `scripts/extract-legacy-study-data.ts`: reproducibly extracts quiz pools and starter decks from legacy artifact.

## Rules

- Use Bun: `bun install`, `bun run <script>`.
- Lessons use query navigation only: `?subject=<id>&topic=<id>`. Do not add path routing or Pages fallback rewrites.
- Validate all external or persisted data. Lesson JSON must never contain raw HTML, script, styles, event handlers, or arbitrary component names.
- Built-in content is immutable JSON. User-created quiz/deck data remains local through versioned localStorage adapters.
- Use shadcn Base UI components, semantic tokens, Lucide icons, accessible labels, visible focus, and 44px touch controls.
- Wrap semantic lesson output in `typeset typeset-docs`; never use Typeset for controls or dialogs.
- `src/content/quizzes.json` and `src/content/flashcards.json` are generated by `bun run extract-legacy-study-data`; change the extractor or legacy source, then regenerate.

## Before handoff

```sh
bun run extract-legacy-study-data
bun run lint
bun run typecheck
bun run test
bun run validate-content
bun run build
```
